# Агент на Android: сервер модели + клиент

Два приложения в одном репозитории (Gradle-модули `:server` и `:app`).

**LLM-сервер** (`server/`): держит Gemma 4 E2B на устройстве (LiteRT-LM) и отдаёт её по HTTP в формате
OpenAI: текст, фото, звук, видео (кадры), инструменты (`tool_calls`). Одна модель и очередь запросов с
ключами и приоритетами клиентов. Описание API: `server/API.md`.

**Агент** (`app/`): чат с голосом, фото и видео, склеенным контекстом, инструментами телефона, MCP-серверами
и Android-агентом. Модель берёт либо встроенную, либо с сервера (Настройки → Модель и инструменты).

## Сборка
1. Один раз запустите workflow **Make keystore** (Actions → Run workflow): он создаст `debug.keystore`,
   которым подписываются оба APK (новые версии ставятся поверх старых).
2. Каждый push собирает оба приложения: Actions → последний запуск → Artifacts → `apks`.
3. Репозиторий лучше сделать приватным: ключ с паролем `android` по сути открытый.

## Первый запуск
1. Установите оба APK.
2. Сервер: «Запустить сервер», «Скачать модель» (~2,6 ГБ), дождитесь «готова (окно N ток.)», «Проверка».
3. Скопируйте ключ клиента с экрана сервера.
4. Агент: Настройки → Модель и инструменты → «Сервер», впишите ключ, «Проверить связь».

Модель держите загруженной только в одном приложении: на 8 ГБ памяти два экземпляра не помещаются.

## Известные ограничения
- Потоковый ответ только без инструментов.
- Видео: берутся кадры, звук из видео не используется.
- Версия LiteRT-LM закреплена (0.18.1) в `build.gradle.kts` обоих модулей.
- Код собирался только через GitHub Actions; часть функций (MCP, Android-агент, подтверждения, окно
  больше 4096 токенов) проверена на телефоне не полностью.
